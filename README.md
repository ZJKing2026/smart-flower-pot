# 智能花盆 — ESP32-S3 毕业设计

基于 ESP32-S3 的智能花盆系统，实现土壤湿度/温湿度/光照实时监测、自动灌溉、OLED 显示与 AI 养护诊断。

## 系统组成

- **硬件固件**（`firmware/`）：ESP32-S3 Arduino 固件，多传感器采集 + 自动/手动浇水控制
- **后端服务**（`backend/`）：Flask API + AI 养护诊断助手 + 植物知识 Agent
- **硬件测试**（各 `*_test/` 目录）：传感器/继电器/蜂鸣器/WiFi 桥接等分项验证草图
- **文档**（`docs/`）：设计、接线说明、测试记录

## 传感器与执行器

| 模块 | 说明 |
|------|------|
| 土壤湿度传感器 | 土壤湿度实时采集 |
| SHT30 / DHT11 | 环境温湿度采集 |
| BH1750 | 光照强度采集 |
| OLED | 数据显示 |
| 水泵 + 继电器 | 自动/手动浇水，最长运行时间保护 |
| 蜂鸣器 | 状态提示 |
| WiFi | 与后端通信，数据上报 |

## 快速开始

1. 使用 Arduino IDE / CLI 打开 `firmware/` 草图，编译烧录到 ESP32-S3
2. 启动后端：`cd backend && pip install -r requirements.txt && python app.py`
3. 传感器阈值、GPIO 定义见各固件代码顶部具名常量

## 开发规范

项目开发规范见 `AGENTS.md`（功能逐项开发、编译验证、硬件安全约束等）。

## 注意事项

- 水泵不得通过 ESP32 3.3V 引脚供电
- 代码中不包含任何 Wi-Fi 密码或 Token，请在本地配置
