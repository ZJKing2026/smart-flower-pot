# 继电器空载测试调试进度

更新时间：2026-07-22

## 已确认事项

- 继电器模块：5V 单路继电器，跳线帽位于 `L`，低电平触发。
- 继电器触点端 `NC/COM/NO` 全程保持空载。
- ESP32-S3 原 `5Vin` 空载电压约为 `4.73V`。
- 使用 ESP32-S3 的 `5Vin` 给继电器供电时，电压降至约 `2.35V`，供电异常。
- 已改用 DCP3512 四路电源模块的独立 5V 输出给继电器供电，并将电源模块 `GND` 与 ESP32 `GND` 共地。
- 手动将继电器 `IN` 与 `DC-` 短接时，继电器指示灯和吸合声音均正常，说明继电器本体、5V供电及低电平触发正常。
- ESP32 下载程序结束时继电器偶尔吸合一次，但程序循环期间继电器不动作。
- 串口能够每5秒交替输出 `Relay: ON` 和 `Relay: OFF`，说明程序循环正常。

## 当前测试程序

- 文件：`relay_no_load_test/relay_no_load_test.ino`
- 控制引脚：`GPIO10`
- 有效电平：低电平吸合
- 测试节奏：吸合5秒、释放5秒，持续循环
- 编译目标：`esp32:esp32:esp32s3`
- 编译结果：程序空间 `313476 bytes (23%)`，动态内存 `21976 bytes (6%)`

## 当前判断

继电器和独立5V供电已经验证正常。剩余问题集中在 `GPIO10 → IN` 控制路径，可能是控制线接错引脚、接触不良，或 GPIO10 实际输出电平未按预期变化。

## 下次继续步骤

1. 暂时断开继电器的 `IN` 控制线。
2. 保持测试程序运行。
3. 万用表调至直流电压档。
4. 黑表笔接 ESP32 `GND`，红表笔直接接板上标注的 `GPIO10` 金属针脚。
5. 连续观察10秒以上：
   - 串口显示 `Relay: ON` 时，预期约为 `0V`。
   - 串口显示 `Relay: OFF` 时，预期约为 `3.3V`。
6. 根据测量结果继续：
   - 若在 `0V/3.3V` 间切换，检查 `GPIO10 → IN` 控制线及接触位置。
   - 若电压不切换，继续排查板卡引脚定义和实际GPIO位置。

## 2026-07-23 实机验证结果

- GPIO10 对 ESP32 GND 的实测电压：
  - `Relay: ON` 时约 `0V`。
  - `Relay: OFF` 时约 `3.288V`。
- 继电器 `IN` 对 `DC-` 的实测电压约为 `0.126V / 3.314V`。
- 继电器手动短接 `IN → DC-` 可以正常吸合和释放。
- 将 GPIO10 从普通推挽输出改为开漏输出 `OUTPUT_OPEN_DRAIN` 后，继电器能够按5秒间隔正常吸合和释放。
- 根因：5V低电平触发继电器输入端与ESP32的3.3V推挽高电平控制方式不兼容；开漏方式在关闭时释放控制线，避免主动输出3.3V造成电平冲突。
- 最终接线：
  - 独立电源模块 `5V → 继电器 DC+`。
  - 独立电源模块 `GND → 继电器 DC-`。
  - 独立电源模块 `GND → ESP32 GND`，两端共地。
  - `ESP32 GPIO10 → 继电器 IN`。
  - 跳线帽保持在 `L`，使用低电平触发。
  - `NC/COM/NO` 保持空载。
- 结论：继电器空载逻辑测试已完成编译、烧录和实机验证。
