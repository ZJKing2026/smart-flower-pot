# ESP32-S3 串口与板卡验证设计

## 目标

使用最小 Arduino 草图确认 ESP32-S3 能够完成编译、烧录、复位和串口输出，为后续外设调试建立可靠基线。

## 行为设计

- 串口波特率固定为 `115200`。
- 启动后等待串口稳定，然后输出一次启动提示。
- 运行期间每秒输出递增的心跳序号，证明主循环持续运行且设备没有反复复位。
- 本阶段不初始化任何传感器、GPIO 外设、Wi-Fi 或存储模块。

## 验收标准

1. 使用 `esp32:esp32:esp32s3` 目标编译成功。
2. 烧录后串口监视器能够看到启动提示。
3. 心跳序号每秒递增且至少连续运行两分钟。
4. 运行期间没有乱码、异常复位信息或心跳序号重新从 1 开始。

## 范围外内容

本阶段不验证具体 ESP32-S3 开发板的 LED、传感器接线和其他外设。
