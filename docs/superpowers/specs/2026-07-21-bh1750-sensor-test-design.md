# GY-30/BH1750 光照采集测试设计

## 目标

使用独立 Arduino 草图验证 GY-30 模块上的 BH1750 能够完成初始化、照度采集、异常判断以及遮挡和照射响应。

## 硬件与通信

- 模块：GY-30
- 传感器：BH1750
- I²C 地址：实机已确认 `0x23`
- ADD：接 GND
- SDA：`GPIO8`
- SCL：`GPIO9`
- I²C 时钟：`100kHz`
- 供电：`3.3V`
- 串口波特率：`115200`

保留 OLED 和 SHT30 的并联接线，但本程序不初始化或读取这两个模块。

## 软件方案

安装并使用 `BH1750` Library。程序显式初始化 `Wire` 的 GPIO8/GPIO9，然后以 `CONTINUOUS_HIGH_RES_MODE` 和地址 `0x23` 初始化 BH1750。

## 采集行为

程序每两秒读取一次照度，输出递增采样编号和一位小数：

```text
Sample #1
Light: 186.7 lx
```

## 异常处理

- 初始化失败：输出地址和五线接线检查提示，不继续读取无效数据。
- 读数小于 `0 lx`：本轮标记为读取失败，不显示伪造数值。
- 读数达到或超过 `65535 lx`：保留原始值并提示可能达到当前模式量程上限。
- 单次读取失败不触发自动重启，后续采样继续尝试。

## 响应测试

1. 在稳定环境光下记录不少于五组数据。
2. 用手完全遮挡传感器感光区域，确认照度明显下降。
3. 移开遮挡，确认读数恢复。
4. 使用手机手电筒从一定距离照射，确认照度明显上升。

测试时不让手机闪光灯或其他高温光源紧贴传感器，避免热量影响模块。

## 验收标准

1. BH1750 Library 安装成功，草图针对 `esp32:esp32:esp32s3` 编译通过。
2. 地址 `0x23` 初始化成功，连续输出不少于五组非负照度数据。
3. 遮挡时读数明显下降，移开遮挡后恢复。
4. 手电筒照射时读数明显上升。
5. 观察期间采样编号连续递增，没有异常归零。

## 范围外内容

本功能不更新 OLED、不进行移动平均滤波、不读取温湿度和土壤湿度，也不根据光照触发蜂鸣器。

## 实机验证记录

- 正常环境光约为 205 lx。
- 完全遮挡后读数低于 10 lx。
- 手机手电筒从一定距离照射时约为 2000 lx。
- 移除遮挡或照射后，读数能够快速恢复至环境光水平。
