# 电容式土壤湿度传感器 ADC 原始值测试设计

## 目标

在没有土壤和花盆的条件下，使用独立 Arduino 草图验证 HW-390 电容式土壤湿度传感器的供电、模拟输出、ESP32-S3 ADC 采集和环境响应能力。本阶段不生成湿度百分比。

## 硬件与接线

- 传感器：Capacitive Soil Moisture Sensor V2.0.0 / HW-390
- 黑线 `GND`：接 ESP32-S3 `GND`
- 红线 `VCC`：接 ESP32-S3 `3V3`
- 黄线 `AOUT`：接 ESP32-S3 `GPIO1`
- 串口波特率：`115200`

所有接线必须在 ESP32-S3 断电状态下完成。只允许白色横线以下的长条探测区域接触土壤或微湿纸巾；元件区、插座和导线接头必须保持干燥。

## ADC 配置

- 分辨率：12 位
- 原始范围：`0～4095`
- 衰减：`ADC_11db`
- 单轮样本数：20
- 样本间隔：5 毫秒
- 输出周期：2 秒

每轮采样统计平均值、最小值和最大值。另使用 `analogReadMilliVolts()` 获取一次校准后的近似毫伏值，便于检查模拟输出是否处于 ESP32 可测范围。

## 串口输出

每轮输出递增采样编号及统计数据：

```text
Sample #1
ADC average: 2876
ADC min/max: 2868 / 2884
Voltage: 2318 mV
```

程序仅报告原始测量，不引用旧代码中的 `AIR_VALUE=3000` 和 `WATER_VALUE=1200`，也不输出湿度百分比。

## 响应测试

1. 探头悬空，记录不少于五组稳定数据。
2. 用手握住白线以下的探测区域，记录不少于五组数据并确认相对悬空值发生变化。
3. 如手握变化不明显，可用微湿但不滴水的纸巾包住白线以下区域，确认数值进一步变化。
4. 移开手或纸巾，确认读数向悬空水平恢复。

测试过程中禁止把整个传感器浸入水中，禁止液体越过白色横线。

## 异常判断

- 平均值持续为 `0`：检查 AOUT、供电和 GPIO1 接线。
- 平均值持续为 `4095`：检查 AOUT 是否过压、悬空或引脚配置错误。
- 同一状态下最小值与最大值差异过大：检查接触不良、供电噪声和杜邦线松动。
- 不同测试状态完全没有变化：检查传感器供电和 AOUT，必要时更换模块复测。

## 验收标准

1. 草图针对 `esp32:esp32:esp32s3` 编译通过，不需要第三方库。
2. 悬空状态连续输出不少于五组非零且非满量程的数据。
3. 手握或微湿纸巾测试后，平均值产生可重复的方向性变化。
4. 移除刺激后，读数向悬空水平恢复。
5. 观察期间采样编号连续递增，没有异常归零。

## 实机测试记录

- 测试日期：2026-07-22
- 开发板：ESP32-S3，Arduino IDE 选择 `ESP32S3 Dev Module`
- 串口设置：`USB CDC On Boot → Enabled`，波特率 `115200`
- 悬空状态：ADC 平均值约 `3282～3285`，电压约 `2679～2687 mV`
- 微湿纸巾包裹：ADC 平均值约 `1387～1541`，电压约 `1141～1325 mV`
- 移除纸巾后的过渡值：ADC 平均值约 `1776～1795`
- 恢复状态：ADC 平均值约 `3294～3315`，电压约 `2692～2704 mV`
- 结论：模拟输出随湿润程度明显下降，移除湿润介质后恢复至悬空水平，原始采集与环境响应验证通过。

## 延期标定

获得实际花盆和土壤后，使用同一传感器记录较干土壤值与浇透排水后的湿土值，再建立 `0%～100%` 映射。正式标定完成前，自动浇水功能不得使用土壤湿度百分比。

## 范围外内容

本功能不读取 I²C 传感器、不更新 OLED、不计算湿度百分比，也不控制继电器或水泵。
