# SH1106 OLED 固定画面测试设计

## 目标

使用独立 Arduino 草图验证 1.3 英寸 SH1106 128×64 OLED 的驱动库、I²C 地址、屏幕方向、完整显示区域和持续刷新能力。

## 硬件与通信

- OLED 控制器：SH1106
- 分辨率：128×64
- I²C 地址：实机已确认 `0x3C`
- SDA：`GPIO8`
- SCL：`GPIO9`
- I²C 时钟：`100kHz`
- OLED 供电：`3.3V`

保留 SHT30 和 GY-30 的现有并联接线，但本程序不初始化或读取这两个传感器。

## 软件方案

使用 U8g2 库的全缓冲硬件 I²C 驱动：

```cpp
U8G2_SH1106_128X64_NONAME_F_HW_I2C
```

程序在初始化 `Wire` 的 GPIO8/GPIO9 后启动 OLED，并显式设置地址 `0x3C << 1`。测试程序使用英文点阵字体，避免在基础验证阶段引入中文字库占用和编码问题。

## 测试画面

屏幕显示以下内容：

```text
Smart Flower Pot
OLED Test
Address: 0x3C
Status: OK   #1
```

同时绘制四周边框。右下角计数器每秒递增，用于确认屏幕能够持续刷新且主循环没有停止。

## 串口行为

串口波特率为 `115200`。启动后输出 OLED 地址和初始化完成信息，每秒输出当前画面计数。串口用于在黑屏时区分程序运行故障和显示故障。

## 异常定位

- 串口计数正常但 OLED 黑屏：检查供电、屏幕方向、驱动型号和显示地址。
- 串口与 OLED 都无输出：检查 USB CDC、端口、烧录结果和板卡复位。
- 画面偏移或边缘缺失：核对 SH1106 驱动和屏幕旋转参数。
- 画面上下颠倒：将旋转参数从 `U8G2_R0` 调整为 `U8G2_R2`，每次只修改该参数。

## 验收标准

1. U8g2 库安装成功，草图针对 `esp32:esp32:esp32s3` 编译通过。
2. 屏幕显示完整边框和四行固定内容。
3. 地址显示为 `0x3C`，计数器每秒递增。
4. 连续观察至少一分钟，无花屏、闪烁、偏移或异常复位。

## 范围外内容

本功能不读取传感器、不显示中文、不实现正式仪表盘布局，也不修改前两个已验证草图。

## 实机验证记录

- OLED 正确显示完整边框和四行测试内容。
- 屏幕方向与显示区域正常，I²C 地址为 `0x3C`。
- 拍照时刷新计数已达到 `#63`，持续刷新超过一分钟。
