# 5V 单路继电器空载测试设计

## 目标

使用独立 Arduino 草图验证 5V 单路继电器模块的供电、低电平触发逻辑、指示灯和机械触点动作。本阶段只进行空载测试，不连接水泵、其他负载或市电。

## 已确认硬件

- 主控：ESP32-S3 N8R2 开发板
- 继电器：单路 5V 继电器模块，继电器本体型号 `SRD-05VDC-SL-C`
- 模块控制端：`DC+`、`DC-`、`IN`
- 模块触点端：`NC`、`COM`、`NO`
- 触发选择：三针 `H/L` 跳线
- 控制 GPIO：`GPIO10`

继电器模块不能直接插入面包板。ESP32-S3 已插在面包板上时，杜邦线一端插入与目标引脚同一横排的空孔，另一端夹入继电器螺丝端子。

## 跳线帽设置

模块上的黑色跳线帽用于短接三针选择器中的两针：

```text
H  ● ● ●  L
```

本测试选择 `L`：断电后，将跳线帽套在中间针和靠近 `L` 字样的针上。

- `IN = LOW`：继电器吸合
- `IN = HIGH`：继电器释放

不得在模块通电时移动跳线帽。

## 接线

所有接线都必须在 ESP32-S3 USB 断开时完成。

| 继电器端子 | ESP32-S3 | 作用 |
|---|---|---|
| `DC+` | `5Vin` | 继电器线圈和模块供电 |
| `DC-` | `GND` | 公共地 |
| `IN` | `GPIO10` | 低电平触发控制 |

`NC`、`COM`、`NO` 在空载测试中全部保持不接。继电器不得接 ESP32-S3 的 `3V3` 供电端。

## 控制程序行为

程序使用 `115200` 波特率输出状态，并按以下顺序运行：

1. 在 GPIO 切换为输出前预置 `HIGH`，保证继电器默认释放。
2. 启动后保持释放 3 秒，便于观察上电状态。
3. 吸合 1 秒，然后释放 3 秒，共执行 3 轮。
4. 三轮结束后永久保持释放，只输出测试完成信息。

程序不使用无限循环反复吸合，避免接线错误时继电器持续动作，也为后续水泵最长运行时间保护建立一致的默认关闭逻辑。

## 预期现象

- 接通 USB 后，继电器模块电源指示灯点亮。
- 前 3 秒继电器不吸合。
- 每轮吸合时出现一次清晰的“咔哒”声，动作指示灯改变。
- 1 秒后出现第二次“咔哒”声并释放。
- 共完成 3 轮，随后保持释放。
- 串口中的 `ON`、`OFF` 状态与实际声音和指示灯一致。

## 异常判断

- 电源指示灯不亮：断电检查 `5Vin → DC+` 和 `GND → DC-`。
- 上电后继电器一直吸合：断电检查跳线帽是否确实位于 `L`，以及 `IN` 是否接到 GPIO10。
- 串口显示 `ON` 但继电器不动作：检查 GPIO10、`IN`、跳线帽和 5V 供电。
- 继电器动作时 ESP32-S3 重启：立即断电，检查短路、接触不良和 5V/GND 接反。
- 动作次数或持续时间与程序不符：停止测试并检查串口输出，不连接任何负载。

## 验收标准

1. 草图针对 `esp32:esp32:esp32s3` 编译通过。
2. 上电默认状态为释放，没有持续误吸合。
3. 继电器按 1 秒吸合、3 秒释放的节奏准确动作 3 次。
4. 串口状态、指示灯和机械声音一致。
5. 测试结束后继电器保持释放，ESP32-S3 没有重启。

## 范围外内容

本功能不连接 `NC`、`COM`、`NO`，不连接水泵，不设计水泵电源，不读取传感器，也不执行自动浇水逻辑。
