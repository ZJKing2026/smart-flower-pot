# ESP32-S3 I²C 总线扫描设计

## 目标

使用独立 Arduino 草图验证 ESP32-S3 的 I²C 总线和外设基础接线，逐步确认 OLED、SHT30 与 BH1750 能够被主控发现。

## 接口定义

- 串口波特率：`115200`
- SDA：`GPIO8`
- SCL：`GPIO9`
- I²C 时钟：`100kHz`
- 扫描地址：`0x01` 至 `0x7E`
- 扫描周期：3 秒

## 接入顺序

1. 只连接 OLED，预期地址为 `0x3C` 或 `0x3D`。
2. 保留 OLED 并连接 SHT30，预期新增地址为 `0x44` 或 `0x45`。
3. 保留前两个模块并连接 BH1750，预期新增地址为 `0x23` 或 `0x5C`。

每增加一个模块都必须重新扫描并确认地址。上一步未通过时，不连接下一个模块。

## OLED 接线

| OLED | ESP32-S3 |
|---|---|
| VDD | 3V3 |
| GND | GND |
| SCK | GPIO9 |
| SDA | GPIO8 |

接线必须在 ESP32-S3 断电状态下完成。当前阶段仅验证 I²C 应答，OLED 不显示内容属于正常情况。

## 程序行为

程序启动后初始化串口和 I²C。每轮扫描依次向所有有效地址发起传输：

- 应答成功时输出十六进制地址。
- 没有设备应答时输出供电和四线接线检查提示。
- 发生其他 I²C 错误时输出对应地址和错误码。
- 每轮结束时输出发现的设备数量。

程序只依赖 Arduino Core 自带的 `Wire` 库，不引入显示屏或传感器驱动库。

## 验收标准

1. 使用 `esp32:esp32:esp32s3` 编译成功。
2. 启用 `USB CDC On Boot` 后，串口监视器能够持续输出扫描结果。
3. 只连接 OLED 时，每轮稳定发现一个相同地址的设备。
4. 连续观察至少三轮，扫描数量和地址保持不变。

## 范围外内容

本功能不初始化 OLED、不显示图形、不读取传感器数据，也不判断扫描到的地址对应哪个具体芯片。

## 实机验证记录

- OLED：连续三轮稳定发现 `0x3C`，单模块扫描数量为 1。
- SHT30：与 OLED 并联后连续两轮稳定发现 `0x3C` 和 `0x44`，扫描数量为 2。
- GY-30/BH1750：三个模块并联后稳定发现 `0x23`、`0x3C` 和 `0x44`，扫描数量为 3。
