# SHT30 温湿度采集测试设计

## 目标

使用独立 Arduino 草图验证 SHT30 的初始化、温度采集、相对湿度采集、异常值判断和环境变化响应能力。

## 硬件与通信

- 传感器：SHT30/SHT3x
- I²C 地址：实机已确认 `0x44`
- SDA：`GPIO8`
- SCL：`GPIO9`
- I²C 时钟：`100kHz`
- 供电：`3.3V`
- 串口波特率：`115200`

保留 OLED 和 GY-30 的并联接线，但本程序不初始化或读取这两个模块。

## 软件方案

安装并使用 `Adafruit SHT31 Library`。程序显式初始化 `Wire` 的 GPIO8/GPIO9，然后使用 `Adafruit_SHT31` 在地址 `0x44` 初始化传感器。

## 采集行为

程序每两秒读取一次温度和相对湿度，并输出一位小数：

```text
Temperature: 25.3 C
Humidity: 58.7 %
```

每组数据附带递增采样编号，方便观察设备是否异常复位。

## 异常处理

- 初始化失败：输出地址和四线接线检查提示，不继续读取无效数据。
- 返回 `NaN`：本轮输出读取失败，不显示伪造数值。
- 温度不在 `-40～125°C`：标记为超出传感器有效范围。
- 相对湿度不在 `0～100%`：标记为超出有效范围。
- 单次失败不触发自动重启；后续采样继续尝试，便于观察故障是否持续。

## 响应测试

先静置观察至少五组数据，确认数值稳定且没有异常。随后用手靠近传感器但不触碰芯片，或从一定距离轻轻呼气，观察温度或湿度连续变化。避免液滴和冷凝水接触传感器。

## 验收标准

1. Adafruit SHT31 Library 及依赖安装成功，草图针对 `esp32:esp32:esp32s3` 编译通过。
2. 地址 `0x44` 初始化成功，连续输出不少于五组有效数据。
3. 温度和相对湿度均在有效范围内，没有 `NaN`。
4. 环境刺激后至少一个参数产生合理、连续的变化，并在移开刺激后逐渐恢复。
5. 观察期间采样编号连续递增，没有异常归零。

## 范围外内容

本功能不显示到 OLED、不进行多次采样滤波、不读取光照和土壤湿度，也不把采集结果用于控制水泵。

## 实机验证记录

- 采样编号连续递增至 47，观察期间没有异常归零。
- 温度稳定在 27.3～27.4°C。
- 湿度受环境刺激后从约 77% 连续回落，并逐步稳定至 54%。
- 全部记录均在有效范围内，未出现 `NaN`。
