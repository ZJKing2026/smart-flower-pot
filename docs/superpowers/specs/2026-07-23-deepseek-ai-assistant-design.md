# DeepSeek 智能养护助手设计

## 目标

在现有 ESP32-S3 本地控制系统之外，增加适合答辩演示的局域网 AI 服务。手机通过浏览器查看实时状态、获取 DeepSeek 养护建议、与花盆助手聊天，并可发送受 ESP32 安全保护的手动浇水指令。

## 范围与边界

- 使用电脑运行 Python 后端，手机、电脑和 ESP32 连接到同一个 Wi-Fi。
- DeepSeek 为主模型；后续可增加通义千问作为备用模型，但第一版不实现自动切换。
- AI 只生成建议和回答问题，不能直接控制水泵。
- 手机的浇水请求必须经电脑后端转发，ESP32 保留最长 3 秒运行保护。
- 自动浇水保持禁用，直到完成真实土壤的干湿标定。
- API Key、Wi-Fi 密码等敏感信息只存放在电脑后端的 `.env` 文件，不写入 ESP32 固件、网页或日志。

## 架构

```text
ESP32-S3 --HTTP--> Python 后端 --HTTPS--> DeepSeek API
    ^                    ^
    |                    |
    +----手动浇水命令---- 手机浏览器
```

### ESP32-S3

- 保留本地传感器采集、OLED、蜂鸣器、继电器、水泵和串口控制。
- 每 5 秒向后端发送温度、湿度、光照、土壤 ADC、告警和水泵状态。
- 接收后端转发的 `water` 与 `stop` 命令；仍由本地代码限制最长浇水时间。
- 断网时继续本地显示、告警与串口手动控制。

### Python 后端

- 提供 ESP32 上报接口、ESP32 命令接口和手机网页接口。
- 在内存中保存最新一份设备状态及最后更新时间。
- 将当前设备状态和用户问题作为上下文发送给 DeepSeek。
- DeepSeek 不可用或未配置时，仍提供实时状态和手动控制功能。

### 手机网页

- 显示温度、湿度、光照、土壤 ADC、告警、水泵状态和设备在线状态。
- 提供“分析当前环境”按钮，获取 AI 养护建议。
- 提供聊天框，询问当前养护相关问题。
- 提供“开始浇水”和“停止浇水”按钮。

## 数据与交互

### ESP32 上报数据

```json
{
  "temperature": 25.2,
  "humidity": 49.9,
  "light": 160.0,
  "soilAdc": 4095,
  "alert": "OK",
  "pump": "OFF"
}
```

### AI 提示约束

- 将实时传感器数据作为上下文。
- 当土壤 ADC 为 `4095`、无效或尚未标定时，明确说明不能据此判断浇水需求。
- 建议应简短、可执行，不编造传感器未提供的数据。
- AI 不返回直接执行硬件操作的指令。

### 手动浇水

1. 手机请求开始或停止浇水。
2. 后端确认 ESP32 最近在线后，转发命令。
3. ESP32 本地执行并返回当前水泵状态。
4. 即使后端或手机断开，ESP32 也会在最长运行时间到达后关闭水泵。

## 异常处理

- ESP32 超过预设时间未上报：网页显示设备离线，保留最后数据和时间。
- 后端不可用：本地硬件功能不受影响。
- DeepSeek API 不可用、密钥缺失或调用失败：网页显示 AI 服务不可用，不影响状态查看和手动浇水。
- 土壤 ADC 异常：仅展示原始值，AI 提示待标定；禁止自动浇水。

## 第一版验收标准

1. 手机能在局域网打开网页并查看 ESP32 最新状态。
2. 传感器读数变化后，网页在一个上报周期内更新。
3. 点击“分析当前环境”可获得 DeepSeek 建议；未配置密钥时获得明确错误提示。
4. 聊天回答包含当前设备状态上下文。
5. 手机可启动并停止水泵，ESP32 保持 3 秒超时保护。
6. 断开后端或网络后，OLED、蜂鸣器和串口控制仍能正常工作。
