# 手动浇水控制设计

## 目标

通过串口监视器手动控制水泵，提供固定时长浇水和紧急停止能力，作为自动浇水之前的独立安全验证功能。

## 范围

- 新建独立草图 `manual_watering_test`，不修改传感器与蜂鸣告警集成草图。
- 继电器 IN 使用 ESP32-S3 GPIO10，保持已验证的开漏输出方式。
- 串口波特率为 115200。
- 不读取传感器，不根据土壤湿度自动浇水，不接入 Wi-Fi。

## 串口命令

- `W` 或 `w`：当水泵关闭时，启动一次手动浇水。
- `S` 或 `s`：立即停止水泵。
- 其他字符：输出帮助提示，不改变水泵状态。

## 安全规则

- 单次手动浇水最长 3 秒，到时强制关闭继电器。
- 水泵运行期间收到重复 `W` 不延长运行时间。
- 上电和复位后先将继电器置为关闭状态。
- 使用非阻塞 `millis()` 计时，以便运行期间仍可处理 `S` 停止命令。
- 水泵不得由 ESP32 的 3.3V 引脚供电；继续使用 DCP3512 的独立输出供电。

## 已验证接线

- DCP3512 `5V` -> 继电器 `DC+`
- DCP3512 `GND` -> 继电器 `DC-`
- DCP3512 `GND` -> ESP32 `GND`
- ESP32 GPIO10 -> 继电器 `IN`
- DCP3512 `3.3V` -> 继电器 `COM`
- 继电器 `NO` -> 水泵红线
- 水泵黑线 -> DCP3512 `GND`
- 继电器 `NC` 不连接

## 验证

1. 上电后串口显示水泵为关闭状态。
2. 发送 `W`，水泵运行约 3 秒后自动停止。
3. 再发送 `W`，运行期间发送 `S`，水泵立即停止。
4. 运行期间重复发送 `W`，水泵总运行时间仍不超过 3 秒。

## 后续限制

正式长期使用前，应在水泵两端并联 1N4007 或等效续流二极管。完成真实干湿土壤标定前，不启用自动浇水。
