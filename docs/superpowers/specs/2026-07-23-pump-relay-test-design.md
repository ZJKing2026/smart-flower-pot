# 水泵继电器单次安全测试设计

日期：2026-07-23

## 目标

验证 ESP32-S3 能够通过继电器控制 3.3V 小型水泵，并确保水泵在限定时间后强制关闭。本阶段不接入土壤湿度判断，不启用自动浇水。

## 硬件条件

- ESP32-S3 开发板。
- 5V 低电平触发单路继电器，跳线帽位于 `L`。
- DCP3512 四路电源模块，由 12V/1.5A 适配器供电。
- 小型直流水泵，已在 3.3V 下完成浸水短时运行验证。
- 继电器控制引脚使用 `GPIO10`，采用开漏输出。

## 接线设计

### 继电器控制侧

- DCP3512 `5V` → 继电器 `DC+`。
- DCP3512 `GND` → 继电器 `DC-`。
- DCP3512 `GND` → ESP32 `GND`，确保可靠共地。
- ESP32 `GPIO10` → 继电器 `IN`。

### 水泵负载侧

- DCP3512 `3.3V` → 继电器 `COM`。
- 继电器 `NO` → 水泵红线。
- 水泵黑线 → DCP3512 `GND`。
- 继电器 `NC` 保持断开。

使用 `NO` 触点，确保系统断电、复位或程序未启动时水泵默认关闭。

## 软件行为

- 使用独立草图目录 `pump_relay_test/`。
- GPIO10 使用 `OUTPUT_OPEN_DRAIN`。
- 启动阶段首先释放继电器，使水泵保持关闭。
- 串口波特率为 `115200`。
- 启动后等待3秒，便于检查水泵、软管和容器位置。
- 水泵仅运行2秒。
- 2秒结束后立即关闭，并在后续循环中持续维持关闭状态。
- 串口依次输出测试开始、倒计时、水泵开启、水泵关闭和测试完成信息。

## 安全要求

- 水泵不得由 ESP32 的 `3V3` 或 `5Vin` 引脚供电。
- 水泵运行前必须浸入水中，禁止干转。
- 出水软管必须朝向接水容器，电子模块远离水源。
- 本测试不得修改2秒最长运行时间。
- 本次短时验证可暂不安装续流二极管；正式系统接入前在水泵两端并联 `1N4007` 或等效二极管，带环端接正极、另一端接负极。
- 未完成土壤湿度实际标定前，不启用自动浇水。

## 验证标准

1. Arduino CLI 使用 `esp32:esp32:esp32s3` 编译通过。
2. 烧录后水泵在等待阶段保持关闭。
3. 等待3秒后继电器吸合，水泵稳定出水。
4. 运行约2秒后继电器释放，水泵停止。
5. 测试完成后水泵不再次启动。
6. 串口输出与实际动作顺序一致。
