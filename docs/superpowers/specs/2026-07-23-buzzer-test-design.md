# 蜂鸣器独立测试设计

日期：2026-07-23

## 目标

验证 ESP32-S3 能够通过 GPIO11 控制 MH-FMD 低电平触发有源蜂鸣器，为后续土壤缺水和光照不足报警提供硬件基础。本阶段不接入传感器阈值逻辑。

## 硬件与接线

- 蜂鸣器模块：MH-FMD 低电平触发有源蜂鸣器。
- 蜂鸣器 `VCC` → ESP32 `3V3`。
- 蜂鸣器 `GND` → ESP32 `GND`。
- 蜂鸣器 `I/O` → ESP32 `GPIO11`。
- GPIO11 当前未连接其他模块。

## 控制逻辑

- GPIO11 输出低电平时蜂鸣器鸣叫。
- GPIO11 输出高电平时蜂鸣器静音。
- 初始化时先将 GPIO11 配置为输入上拉，再预置高电平，最后切换为普通输出，避免初始化期间误鸣。
- 串口波特率为 `115200`。
- 启动后等待3秒。
- 蜂鸣器鸣叫300毫秒、静音300毫秒，共执行3次。
- 测试结束后持续输出高电平，使蜂鸣器永久静音。
- 串口输出测试开始、倒计时、每轮编号、鸣叫、静音和测试完成状态。

## 文件边界

- 新建独立草图：`buzzer_test/buzzer_test.ino`。
- 不修改现有传感器、继电器和水泵测试程序。
- 不加入阈值判断、自动浇水或网络功能。

## 验证标准

1. Arduino CLI 使用 `esp32:esp32:esp32s3` 编译通过。
2. 启动等待阶段蜂鸣器保持静音。
3. 等待3秒后蜂鸣器发出3次清晰短鸣。
4. 每次鸣叫和静音时间约为300毫秒。
5. 三次短鸣结束后蜂鸣器不再响。
6. 串口输出与实际声音顺序一致。

## 后续用途

蜂鸣器独立测试通过后，再在正式集成程序中用于土壤缺水、光照不足和传感器异常提示。报警策略需单独设计，避免持续鸣叫和重复触发干扰。
