## 硬件与接线

- 模块：MH-FMD 低电平触发有源蜂鸣器。
- 蜂鸣器 `VCC` → ESP32 `3V3`。
- 蜂鸣器 `GND` → ESP32 `GND`。
- 蜂鸣器 `I/O` → ESP32 `GPIO11`。

## 软件

- 草图：`buzzer_test/buzzer_test.ino`。
- 启动后等待3秒。
- 蜂鸣器短鸣3次，每次鸣叫300毫秒、静音300毫秒。
- 测试完成后持续保持静音。
