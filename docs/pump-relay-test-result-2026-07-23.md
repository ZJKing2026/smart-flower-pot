# 水泵继电器单次测试记录

日期：2026-07-23

## 接线

- DCP3512 `5V` → 继电器 `DC+`。
- DCP3512 `GND` → 继电器 `DC-`。
- DCP3512 `GND` → ESP32 `GND`。
- ESP32 `GPIO10` → 继电器 `IN`。
- DCP3512 `3.3V` → 继电器 `COM`。
- 继电器 `NO` → 水泵红线。
- 水泵黑线 → DCP3512 `GND`。
- 继电器 `NC` 未连接。

## 软件

- 草图：`pump_relay_test/pump_relay_test.ino`。
- GPIO10 使用开漏输出 `OUTPUT_OPEN_DRAIN`。
- 启动后等待3秒，水泵运行2秒，随后永久关闭。

## 验证结果

- Arduino CLI 编译通过。
- 程序空间：`313324 bytes (23%)`。
- 动态内存：`21976 bytes (6%)`。
- 实机观察：继电器能够控制水泵启动和停止。
- 水泵在限定的2秒后停止，测试结束后未再次启动。
- 结论：水泵继电器单次安全测试通过。
